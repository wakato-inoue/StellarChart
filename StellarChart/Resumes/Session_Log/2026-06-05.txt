StellarChart DB移行 セッションログ
===================================
日付: 2026-06-05

概要
----
タスク管理アプリ StellarChart のデータアクセス層を、
グローバル配列 (tasks / projects / transfers) の直接参照から
Repository パターン経由に移行するプロジェクト。

目的: 将来の DB/API バックエンド移行を可能にするため、
      全データアクセスを repository.js に集約する。

成果物
------
1. 設計文書: Resumes/DB移行仕様.txt
   - データアクセスパターン棚卸し
   - Repository インターフェース設計
2. 実装: js/data/repository.js (204行)
   - taskRepo (findById / findByProject / findByParent / hasChildren /
     findAll / getLeaves / save / delete / deleteWithChildren /
     deleteByProject / nextWBSCode / syncWBSCodes)
   - projectRepo (findById / findAll / findVisible / save / delete)
   - transferRepo (findByTargetUser / findAll / save)

移行完了ファイル (全11ファイル)
-------------------------------
1. js/globals.js         - IIFE → taskRepo.syncWBSCodes()
2. js/helpers.js         - 全13関数を repository 経由に
3. js/dialogs/task-form.js   - find/save → taskRepo.save
4. js/dialogs/task-detail.js - tasks.find(×4) → taskRepo.findById
5. js/components/tasks.js    - tasks=filter → taskRepo.delete/deleteWithChildren
6. js/components/projects.js - projects=filter → projectRepo.delete
7. js/dialogs/project-form.js - findIndex/push → projectRepo.save
8. js/components/issues.js    - transfers.filter/unshift → transferRepo.findByTargetUser/save
9. js/components/wbs.js       - tasks.filter(×3) → findByProject+filter
10. js/dialogs/employee.js    - projects.find(×3) → projectRepo.findById
11. js/dialogs/login.js       - 対象外 (employeeMaster のみ)

その他
