【結論】重大な問題なし

--------------------------------------------------------------------------------
確認済（問題なし）
--------------------------------------------------------------------------------

1. 変数の重複宣言なし
   すべての let / const は各ファイルで1回のみ。
   - globals.js: 9個の状態変数
   - task-detail.js: currentDetailTaskId
   - issues.js: transferTaskId

2. script読み込み順に問題なし
   data.js → auth.js → globals.js → helpers.js → utils →
   components → view-switcher → dialogs → login → app.js
   前方参照が発生する箇所はなく、すべての依存が満たされている。

3. auth.js の RANK_LEVEL 参照
   data.js の実体は RANK_LEVEL（コメントの RANK_LEVELS は typo）。
   動作には影響しない。

4. 関数の競合なし
   全17ファイルで同名関数は存在しない。

5. グローバル変数の TDZ（Temporal Dead Zone）問題なし
   関数内で参照されるグローバル変数（currentUser, currentView など）は
   すべて関数実行時（定義時ではない）に評価されるため、
   読み込み順が前後しても安全。

--------------------------------------------------------------------------------
軽微な指摘
--------------------------------------------------------------------------------

1. globals.js のコメント（3行目）
   「helpers.js の前に読み込むこと」とあるが、
   本来の制約は data.js の後であること（IIFE内で tasks を使用）。
   data.js → globals.js → helpers.js の現在の順序では問題なし。
   指摘対象ファイル: js/globals.js L3

2. data.js 8行目のコメント
   RANK_LEVELS と書かれているが実際の定数名は RANK_LEVEL（末尾Sの有無）。
   動作には影響しない。
   指摘対象ファイル: js/data.js L8

3. login.js のイベントリスナー重複リスク
   showLoginDialog() が複数回呼ばれると btnLogin にリスナーが重複する。
   現状は DOMContentLoaded で1回のみの呼び出しなので問題ないが、
   将来的に再呼び出しが必要になった場合の注意点。
   指摘対象ファイル: js/dialogs/login.js L43
